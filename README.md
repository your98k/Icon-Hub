## 上传图标

1. 打开 [icons 文件夹](https://github.com/your98k/Icon-Hub/tree/main/icons)，点击 **Add file → Upload files**。
2. 拖入或选择 PNG、JPG、SVG 或 WebP 图标，填写说明并点击 **Commit changes**。
3. 图标名称建议使用英文、数字和连字符，例如 `My-App.png`；同名文件更新后，原链接保持不变，缓存可能需要一点时间刷新。

## 引用图标

将下方地址中的文件名换成上传的文件名：

```text
https://raw.githubusercontent.com/your98k/Icon-Hub/main/icons/My-App.png
```

Stash 覆写示例：

```yaml
icon: 'https://raw.githubusercontent.com/your98k/Icon-Hub/main/icons/My-App.png'
```

文件为公开访问，请只上传愿意公开分享的图片。
